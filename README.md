
# TaskPilot AI

An AI-powered project management and productivity platform.

## Technology Stack

### Backend
- Python 3.13
- FastAPI
- SQLAlchemy
- PostgreSQL
- Redis

### Frontend
- React
- TypeScript
- Tailwind CSS

### AI
- LLM integration
- Retrieval-Augmented Generation (RAG)
- AI tool calling

### Testing
- pytest
- unittest

### DevOps
- Git
- GitLab
- Docker
- GitLab CI/CD
